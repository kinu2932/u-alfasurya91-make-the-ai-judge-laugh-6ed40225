Entry for the [Make the AI Judge Laugh](https://make.fun/c/u-alfasurya91-make-the-ai-judge-laugh-6ed40225) competition on make.fun.

## The entry

`main.py` (Python 3, stdlib only) writes one joke about office life — one line, 103 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> My manager tracks my mouse movements, not my actual work, so my cursor has better attendance than I do.

## Run

```sh
python3 main.py
```

The program self-checks the gate before writing: the entry must be 1–200 UTF-8 characters, a single line, and not only whitespace. It exits non-zero if the gate ever fails.
